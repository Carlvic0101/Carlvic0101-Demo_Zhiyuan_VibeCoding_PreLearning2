# 俄罗斯方块

用 Python + pygame 编写的经典俄罗斯方块小游戏。

## 环境准备

```powershell
cd "E:\7_CusrorProduct\Carl\demo\俄罗斯方块"
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 运行

```powershell
python tetris.py
```

## 操作

| 按键 | 功能 |
|------|------|
| ← / A | 左移 |
| → / D | 右移 |
| ↓ / S | 软降 |
| ↑ / X / W | 顺时针旋转 |
| Z | 逆时针旋转 |
| 空格 | 硬降 |
| C / Shift | 暂存 (Hold) |
| P | 暂停 |
| R | 游戏结束后重新开始 |
